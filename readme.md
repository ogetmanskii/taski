Утилита для управления процессами и запуска скриптов в Windows.

## Начало работы

1.  Создайте папку для вашего окружения (например **sample-env**).
2.  В этой папке создайте файл **environment.yml**.
2.  В файле **environment.yaml** опишите сервисы по примеру из папки **examples**.
3.  Добавьте скрипты в папку окружения: bat файлы, lua файлы, sh файлы.
4.  Запустите утилиту с указанием рабочей директории sample-env, либо с параметром: `cli -d sample-env`.

Утилита имеет интерфейс командной строки: `cli -h`, а также интерактивное консольное меню: `cli menu` или просто `cli`.

## Выполнение скриптов

*   Скрипты bat выполняются стандартно через команду `cmd.exe /c file.bat`.
*   Скрипты sh выполняются с помощью WSL, через команду `wsl ./file.sh`.
*   Скрипты lua выполняются через встроенный интерпретатор языка Lua.

## Дополнительные функции Lua

В Lua скриптах доступны полезные функции:

*   Скачать файл по HTTP / HTTPS адресу и поместить по указанному пути: `download_file(url, localPath)`.
*   Распаковать ZIP архив в указанную папку: `extract_zip_file(zipFilePath, destDir)`.

В остальном в Lua скриптах доступны стандартные библиотеки этого языка.

Подробнее о программировании на языке Lua: [lua.org](https://www.lua.org/pil/contents.html).
