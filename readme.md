Утилита для управления процессами и запуска shell скриптов в Windows. 

Позволяет организовать рабочее окружение с `.env` файлом, настроенными сервисами и набором shell задач.

## Начало работы

1.  Создайте папку для вашего окружения (например **sample-env**).
2.  В этой папке создайте файл **environment.yml**.
2.  Добавьте сервисы в секцию `services:`. Опишите сервисы по примеру из папки [examples](./examples/).
3.  Добавьте shell скрипты в секцию `tasks:`. См. примеры в папке [examples](./examples/).
4.  Запустите утилиту с указанием рабочей директории sample-env, либо с параметром: `cli -d sample-env`.

Утилита имеет интерфейс командной строки: `cli -h`, а также интерактивное консольное меню: `cli menu` или просто `cli`.
