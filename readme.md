Утилита для управления локальным окружением разработки в Windows. 

Позволяет описывать фоновые сервисы (БД, очереди, веб-серверы) и задачи (миграции, сборка, сидирование) в декларативном файле `environment.yml`.

## Назначение

Инструмент для Windows, заменяющий:

* docker-compose для нативных процессов
* Makefile / Taskfile с управлением службами

Позволяет стандартизировать запуск окружения, сократить количество открытых терминалов и упростить управление фоновыми процессами.

## Возможности

* Декларативное описание окружения в YAML.
* Разрешение зависимостей между сервисами (`depends-on`).
* Мониторинг состояния процессов по имени исполняемого файла, аргументам командной строки и healthcheck-командам.
* Запуск shell-команд с поддержкой цепочек, зависимостей и скрытых задач.
* Шаблонизация конфигурации через [Inja](https://github.com/pantor/inja).
* Автоматическая подгрузка переменных из `.env`.
* Меню в командной строке (`cli menu`).

## Преимущества

* Минимальный размер: утилита весом всего `1mb`.
* Минимальное потребление ресурсов: занимает всего `2mb` в оперативной памяти.
* Только системные API и нативные процессы: Docker, WSL, Hypervisor — не требуются.

## Установка

1. Загрузите последнюю версию из [Releases](https://github.com/ogetmanskii/taski/releases)
2. Разместите `cli` в директории, доступной через `PATH`, либо используйте полный путь

## Быстрый старт

1. Создайте папку проекта и перейдите в неё:

```
mkdir my-backend-project
cd my-backend-project
```

2. Создайте файл `.env` для локальных путей и учётных данных:

```
# .env
PGSQL_HOME=C:/Postgres
PG_USER=postgres
PG_PASSWORD=postgres
```

3. Создайте файл `environment.yml`:

```yaml
# environment.yml
services:
  postgres:
    utf8: true
    work-dir: ${PGSQL_HOME}
    env:
      PGPORT: 15433
    start: 
      cmd: bin\pg_ctl start -D data -l postgres.txt
      timeout: 10
    process-filter: ${PGSQL_HOME}/bin/postgres.exe
    healthcheck:
      cmd: bin\pg_isready -h localhost -d postgres -U postgres
      interval: 2.5
      timeout: 15
    stop: bin\pg_ctl stop -D data
    
tasks:
  create-db:
    name: Create dev database
    work-dir: ${PGSQL_HOME}
    cmd: bin\createdb -U ${PG_USER} myapp_dev
```

4. Запустите:

```bash
cli
# или
cli menu
```

## Интерфейс командной строки

```
cli [OPTIONS] [SUBCOMMANDS]

OPTIONS:
  -h,     --help              Справка
  -d,     --dir TEXT:DIR      Рабочая директория (по умолчанию текущая)
  -f,     --file TEXT:FILE    Файл конфигурации (по умолчанию environment.yml)
  -e,     --env TEXT:FILE     Файл .env (по умолчанию .env)
          --no-color, --nc    Бесцветный режим для вывода в консоли
  -v,     --version           Версия

SUBCOMMANDS:
  list                        Список сервисов и задач
  up                          Запуск всех сервисов
  down                        Остановка всех сервисов
  run                         Запуск задач
  ps                          Статус сервисов
  menu                        Показать меню
```

## Конфигурация

### Секция `services`

Определяет фоновые процессы.

| Ключ             | Тип                    | Обязательный | Описание                                                                                           |
|------------------|------------------------|--------------|----------------------------------------------------------------------------------------------------|
| `name`           | string                 | Нет          | Отображаемое имя. По умолчанию — ключ из YAML.                                                     |
| `work-dir`       | string                 | Нет          | Рабочая директория. По умолчанию - текущая директория утилиты.                                     |
| `env`            | map                    | Нет          | Дополнительные переменные окружения.                                                               |
| `utf8`           | bool                   | Нет          | Кодировка вывода в UTF-8. По умолчанию `false`.                                                    |
| `depends-on`     | string / list          | Нет          | Сервисы, которые должны быть запущены перед данным.                                                |
| `start`          | string / list / object | Да           | Команда запуска.                                                                                   |
| `process-filter` | string / object        | Нет          | Фильтр процессов для мониторинга. Если не указан, сервис можно только запустить, но не остановить. |
| `stop`           | string / list / object | Нет          | Команда остановки. Если не указана, отправляется SIGTERM процессам из `monitorProcess`.            |
| `healthcheck`    | object                 | Нет          | Правило проверки здоровья сервиса.                                                                 |

#### Секции `start` и `stop`

Определяет параметры запуска shell команд.

| Ключ                       | Тип           | Обязательный | Описание                                                   |
|----------------------------|---------------|--------------|------------------------------------------------------------|
| `cmd`                      | string / list | Да           | Shell команда - одна или перечень команд.                  |
| `work-dir`                 | string        | Нет          | Рабочая директория.                                        |
| `env`                      | map           | Нет          | Дополнительные переменные окружения.                       |
| `utf8`                     | bool          | Нет          | Кодировка вывода в UTF-8. По умолчанию `false`.            |
| `create-new-process-group` | bool          | Нет          | Выделить ли процесс в отдельную группу.                    |
| `detach-after-seconds`     | float         | Нет          | Отсоединиться от процесса через N секунд.                  |
| `detach-after-messages`    | string        | Нет          | Отсоединиться от процесса после получения указанной фразы. |
| `timeout`                  | float         | Нет          | Таймаут ожидания команды N секунд.                         |
| `exit-codes`               | list          | Нет          | Список успешных кодов возврата для данной команды.         |

#### Секция `process-filter`

Определяет параметры поиска активного процесса, чтобы определить статус сервиса (запущен / не запущен).

| Ключ       | Тип    | Обязательный | Описание                            |
|------------|--------|--------------|-------------------------------------|
| `exe`      | string | Да           | Шаблон исполняемого файла.          |
| `args`     | string | Нет          | Шаблон аргументов командной строки. |
| `work-dir` | string | Нет          | Шаблон рабочей директории процесса. |

#### Секция `healthcheck`

Правило проверки здоровья сервиса.

| Ключ         | Тип           | Обязательный | Описание                                                       |
|--------------|---------------|--------------|----------------------------------------------------------------|
| `cmd`        | string / list | Да           | Команда для проверки.                                          |
| `work-dir`   | string        | Нет          | Рабочая директория. Если не указана, наследуется от сервиса.   |
| `env`        | map           | Нет          | Переменные окружения. Если не указаны, наследуются от сервиса. |
| `utf8`       | bool          | Нет          | Режим UTF-8. Если не указан, наследуется от сервиса.           |
| `exit-codes` | list          | Нет          | Ожидаемые коды возврата команды. По умолчанию `0`.             |
| `interval`   | float         | Нет          | Интвервал проверки в секундах. По умолчанию `5`.               |
| `timeout`    | float         | Нет          | Таймаут выполнения `command` в секундах. По умолчанию `30`.    |

### Секция `tasks`

Определяет исполняемые задачи.

| Ключ         | Тип           | Обязательный | Описание                                                       |
|--------------|---------------|--------------|----------------------------------------------------------------|
| `name`       | string        | Нет          | Отображаемое имя.                                              |
| `hidden`     | bool          | Нет          | Скрыть задачу из меню (для задач, используемых в `dependsOn`). |
| `depends-on` | string / list | Нет          | Задачи, выполняемые перед данной (один раз за сессию).         |
| `before`     | string / list | Нет          | Задачи, выполняемые перед данной (всегда).                     |
| `after`      | string / list | Нет          | Задачи, выполняемые после данной (всегда).                     |
| `cmd`        | string / list | Да           | Команда или список команд (объединяются через `&&`).           |
| `work-dir`   | string        | Нет          | Рабочая директория.                                            |
| `timeout`    | float         | Нет          | Таймаут выполнения `command` в секундах.                       |
| `exit-codes` | list          | Нет          | Коды возврата, считающиеся успешными (например, `[0, 1]`).     |
| `env`        | map           | Нет          | Переменные окружения.                                          |
| `utf8`       | bool          | Нет          | Кодировка вывода.                                              |
