Утилита для управления локальным окружением разработки в Windows. 

Позволяет описывать фоновые сервисы (БД, очереди, веб-серверы) и задачи (миграции, сборка, сидирование) в декларативном файле `environment.yml`.

## Назначение

Инструмент для Windows, заменяющий:

* docker-compose для нативных процессов
* Makefile/Taskfile с управлением службами

Позволяет стандартизировать запуск окружения, сократить количество открытых терминалов и упростить управление фоновыми процессами.

## Возможности

* Декларативное описание окружения в YAML.
* Разрешение зависимостей между сервисами (`dependsOn`).
* Мониторинг состояния процессов по имени исполняемого файла, аргументам командной строки и healthcheck-командам.
* Поддержка пользовательских команд остановки (`stopCommand`) или отправка SIGTERM.
* Запуск shell-команд с поддержкой цепочек, зависимостей и скрытых задач.
* Шаблонизация конфигурации через [Inja](https://github.com/pantor/inja).
* Автоматическая подгрузка переменных из `.env`.
* Меню в командной строке (`cli menu`).

## Преимущества

* Минимальный размер: утилита весом всего `1mb`.
* Минимальное потребление ресурсов: занимает всего `2mb` в оперативной памяти.
* Только системные API и нативные процессы: Docker, WSL, Hypervisor — не требуются.

## Установка

1. Загрузите последнюю версию из [Releases](https://github.com/ogetmanskii/taski/releases)
2. Разместите `cli` в директории, доступной через `PATH`, либо используйте полный путь

## Быстрый старт

1. Создайте папку проекта и перейдите в неё:

```
mkdir my-backend-project
cd my-backend-project
```

2. Создайте файл `.env` для локальных путей и учётных данных:

```
# .env
PG_USER=myuser
PG_PASSWORD=s3cret
```

3. Создайте файл `environment.yml`:

```yaml
# environment.yml
services:
  postgres:
    name: PostgreSQL
    startCommand: pg_ctl start -D data -l logfile.txt
    stopCommand: pg_ctl stop -D data
    monitorProcess: postgres.exe
    detachAfterMessage: database system is ready to accept connections
    
tasks:
  create-db:
    name: Create dev database
    command: createdb -U ${PG_USER} myapp_dev
```

4. Запустите:

```bash
cli
# или
cli menu
```

## Интерфейс командной строки

```
cli [OPTIONS] [SUBCOMMANDS]

OPTIONS:
  -h,     --help              Справка
  -d,     --dir TEXT:DIR      Рабочая директория (по умолчанию текущая)
  -f,     --file TEXT:FILE    Файл конфигурации (по умолчанию environment.yml)
  -e,     --env TEXT:FILE     Файл .env (по умолчанию .env)
          --no-color, --nc    Бесцветный режим для вывода в консоли
  -v,     --version           Версия

SUBCOMMANDS:
  list                        Список сервисов и задач
  up                          Запуск всех сервисов
  down                        Остановка всех сервисов
  run                         Запуск задач
  ps                          Статус сервисов
  menu                        Показать меню
```

## Конфигурация

### Секция `services`

Определяет фоновые процессы.

| Ключ                 | Тип           | Обязательный | Описание                                                                                |
|----------------------|---------------|--------------|-----------------------------------------------------------------------------------------|
| `name`               | string        | Нет          | Отображаемое имя. По умолчанию — ключ из YAML.                                          |
| `utf8`               | bool          | Нет          | Кодировка вывода в UTF-8. По умолчанию `true`.                                          |
| `dependsOn`          | string/list   | Нет          | Сервисы, которые должны быть запущены перед данным.                                     |
| `workingDirectory`   | string        | Нет          | Рабочая директория.                                                                     |
| `environment`        | map           | Нет          | Дополнительные переменные окружения.                                                    |
| `startCommand`       | string/list   | Да           | Команда запуска.                                                                        |
| `detachAfterSeconds` | int           | Нет          | Отсоединение через N секунд.                                                            |
| `detachAfterMessage` | string        | Нет          | Отсоединение при появлении строки в выводе.                                             |
| `monitorProcess`     | string/object | Нет          | Процесс для мониторинга. Если не указан, сервис только запускается.                     |
| `stopCommand`        | string        | Нет          | Команда остановки. Если не указана, отправляется SIGTERM процессам из `monitorProcess`. |
| `healthcheck`        | object        | Нет          | Правило проверки здоровья сервиса.                                                      |

#### Секция `healthcheck`

Правило проверки здоровья сервиса.

| Ключ               | Тип         | Обязательный | Описание                                                                   |
|--------------------|-------------|--------------|----------------------------------------------------------------------------|
| `command`          | string/list | Да           | Команда для проверки. Наследует workingDirectory и environment от сервиса. |
| `workingDirectory` | string      | Нет          | Рабочая директория. Если не укащана, наследуется от сервиса.               |
| `environment`      | map         | Нет          | Переменные окружения. Если не указаны, наследуются от сервиса.             |
| `utf8`             | bool        | Нет          | Режим UTF-8. Если не указан, наследуется от сервиса.                       |
| `exitCodes`        | list        | Нет          | Ожидаемые коды возврата команды. По умолчанию `0`.                         |
| `interval`         | int         | Нет          | Интвервал проверки в секундах. По умолчанию `5`.                           |
| `timeout`          | int         | Нет          | Таймаут выполнения `command` в секундах. По умолчанию `30`.                |

### Секция `tasks`

Определяет исполняемые задачи.

| Ключ               | Тип         | Обязательный | Описание                                                       |
|--------------------|-------------|--------------|----------------------------------------------------------------|
| `name`             | string      | Нет          | Отображаемое имя.                                              |
| `hidden`           | bool        | Нет          | Скрыть задачу из меню (для задач, используемых в `dependsOn`). |
| `dependsOn`        | string/list | Нет          | Задачи, выполняемые перед данной (один раз за сессию).         |
| `before`           | string/list | Нет          | Задачи, выполняемые перед данной (всегда).                     |
| `after`            | string/list | Нет          | Задачи, выполняемые после данной (всегда).                     |
| `command`          | string/list | Да           | Команда или список команд (объединяются через `&&`).           |
| `workingDirectory` | string      | Нет          | Рабочая директория.                                            |
| `timeout`          | int         | Нет          | Таймаут выполнения `command` в секундах.                       |
| `exitCodes`        | list        | Нет          | Коды возврата, считающиеся успешными (например, `[0, 1]`).     |
| `environment`      | map         | Нет          | Переменные окружения.                                          |
| `utf8`             | bool        | Нет          | Кодировка вывода.                                              |
